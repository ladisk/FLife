# FLife logo

The mark is a response PSD with a broadband rise and a resonance peak. The falling flank of the peak turns into the S-N line, bends at the knee and continues as the flat endurance limit, which underlines the wordmark.

Colours: graphite `#23272B` and red `#C8102E`. The dark variants use `#ECEAE5` and `#FF4F64`. Font: IBM Plex Sans SemiBold, converted to outlines, so no font is needed to display the SVG files.

| File | Use |
|---|---|
| `flife-icon.svg`, `flife-icon.png` (512 px) | Icon |
| `flife-logo.svg`, `flife-logo-dark.svg` | Icon and wordmark on light and dark backgrounds (docs) |
