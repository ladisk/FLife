# FLife logo

The mark is a response PSD with a dominant resonance peak.

| File | Use |
|---|---|
| `flife-icon.svg`, `flife-icon.png` (512 px) | Icon, avatars, README |
| `flife-logo.svg` | Icon and wordmark on light backgrounds |
| `flife-logo-dark.svg` | Icon and wordmark on dark backgrounds |
| `favicon.svg`, `favicon.ico` (16/32/48 px) | Favicon; simplified curve for small sizes |
| `flife-social.svg`, `flife-social.png` | GitHub social preview (1280 × 640) |

Text in the SVG files is converted to outlines, so no font is needed to display them.

## Colours

| Name | Hex | Use |
|---|---|---|
| Ink | `#0F1E2E` | Text, icon background |
| Resonance | `#F97316` | Accent on dark backgrounds |
| Resonance deep | `#C2410C` | Accent and links on light backgrounds |
| Steel | `#4F5D6B` | Secondary text, axes |
| Rule | `#DEE2E6` | Borders, grid lines |
| Paper | `#F7F7F4` | Page background |

## Type

[IBM Plex Sans](https://github.com/IBM/plex) (SemiBold for the wordmark) and IBM Plex Mono for code, both under the SIL Open Font License.
